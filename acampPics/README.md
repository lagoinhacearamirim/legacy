# Fotos do Acamp

Esta pasta está reservada para as fotografias oficiais do Acamp anterior, que serão enviadas pela liderança.

Enquanto elas não chegam, a galeria utiliza **sete imagens ilustrativas temporárias hospedadas no Unsplash**, cadastradas em `../acamp/photos.json`. Elas servem apenas para visualizar o layout e **não representam registros do Legacy nem da Pousada Dunamis**.

## Quando as fotos oficiais chegarem

Coloque os arquivos nesta pasta e substitua os endereços temporários em `acamp/photos.json` por caminhos locais, por exemplo: `../acampPics/foto-01.jpg`. O layout e os espaços da galeria já estão preparados para receber as novas imagens.
