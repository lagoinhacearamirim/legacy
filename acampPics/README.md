# Fotos do ACAMP

Adicione aqui as fotos do Acampamento anterior. Depois, cadastre os caminhos relativos e as descrições em `/acamp/photos.json`.

Exemplo de caminho usado no JSON: `../acampPics/foto-01.jpg`.

Dê preferência a imagens em JPG, PNG ou WebP, com boa resolução. As fotos serão recortadas automaticamente para se adaptar aos cartões da landing page.
